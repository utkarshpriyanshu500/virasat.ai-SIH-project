# 🇮🇳 Virasat.ai — Artifacts of India

> **Discover. Understand. Preserve. Celebrate.**

Virasat.ai is a digital platform dedicated to India's rich cultural heritage. It brings together information about traditional **art, crafts, dance, textiles, monuments, traditions, and cultural practices** in an interactive and accessible experience.

The project aims to make India's diverse heritage easier to discover while encouraging awareness, appreciation, and preservation for future generations.

---

## 🌏 Why Virasat.ai?

India has one of the world's most diverse cultural heritages, but information about many traditional practices remains scattered across different sources.

Virasat.ai provides a centralized digital experience where users can:

- 🔎 Discover Indian cultural heritage
- 🏛️ Explore historical monuments and sites
- 🎨 Learn about traditional arts and crafts
- 💃 Explore classical and traditional dance forms
- 🧵 Discover Indian textiles and handicrafts
- 🗺️ Explore heritage through an interactive map
- 🖼️ Browse a dedicated visual/image archive
- 📚 Learn about the history and significance of cultural artifacts

---

## ✨ Key Features

### 🏛️ Heritage Explorer

Explore different categories of Indian heritage, including:

- Monuments
- Classical & folk dances
- Traditional crafts
- Paintings
- Textiles
- Handicrafts
- Cultural traditions

Each entry provides relevant information about its history, location, significance, and cultural importance.

### 🗺️ Interactive Heritage Map

Discover heritage locations across India through an interactive map.

Users can explore different heritage sites and understand their geographical and cultural context.

### 🖼️ Virasat Image Archive

A dedicated visual archive for discovering images related to India's cultural heritage.

The gallery is designed to make visual exploration easier, similar to an image-search experience focused specifically on Indian heritage.

### 🤖 AI-Powered Exploration

Virasat.ai is designed to incorporate AI-powered experiences that can help users understand and explore cultural heritage in a more interactive way.

### 🌐 Accessible Digital Heritage

The platform is designed to make heritage information accessible to students, researchers, travelers, enthusiasts, and anyone interested in India's culture.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/virasat-ai.git
cd virasat-ai
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file and add the required environment variables.

Example:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_key
GEMINI_API_KEY=your_gemini_key
```

> **Never commit `.env.local` or private API keys to GitHub.**

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🌐 Deployment

Virasat.ai can be deployed using **Vercel**.

After connecting the GitHub repository to Vercel:

1. Import the repository.
2. Select the Next.js framework.
3. Add the required environment variables.
4. Deploy the project.

The deployed website can then be accessed publicly without requiring the developer's computer to remain online.

## 🔐 Security

Sensitive information should **never** be committed to this repository.

Make sure files containing secrets are included in `.gitignore`:

```text
.env
.env.local
.env*.local
```

API keys and database credentials should be stored securely using environment variables.
